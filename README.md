# 🎬 MovieBox - Team Collaboration Project

Welcome to the **MovieBox** project repository! This is a collaborative web application built using Vanilla JavaScript and the TMDB API.

## 🚀 Project Goal
To build, manage, and scale a feature-rich Single Page Application (SPA) movie streaming dashboard as a team using Git and GitHub workflows (Branches, Pull Requests, Issues, and Code Reviews).

## 🛠️ Tech Stack
- **Core:** HTML5, CSS3, Vanilla JavaScript (ES Modules)
- **Bundler:** Vite
- **API:** TMDB (The Movie Database) API
- **Icons:** Lucide Icons
- **Storage:** LocalStorage (for Favorites & Watchlist)
- **Version Control:** Git & GitHub

## 👥 Team Collaboration Workflow
1. **Issues & Project Board:** All tasks are tracked using GitHub Issues and the Kanban Project Board.
2. **Branching Strategy:** 
   - `main`: Production-ready code.
   - `feat/*` or `fix/*`: Feature and bug fix branches.
3. **Pull Requests (PR):** Code changes must be reviewed and approved via PR before merging into `main`.
